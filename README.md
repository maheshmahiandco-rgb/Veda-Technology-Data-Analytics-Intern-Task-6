What is the difference between SUMIF and SUMIFS?

SUMIF evaluates only a single condition (syntax: range, criteria, [sum_range]). SUMIFS handles multiple criteria and puts the sum_range first (syntax: sum_range, criteria_range1, criteria1, ...).

How does XLOOKUP improve on VLOOKUP?

XLOOKUP defaults to an exact match, looks both left and right, does not require column index numbers, and includes built-in error handling (if_not_found).

When would you use INDEX/MATCH instead of VLOOKUP?

Use INDEX/MATCH when working in older Excel versions lacking XLOOKUP, as it allows leftward lookups and performs faster on large datasets than VLOOKUP
